# Session 3 independent review

Verdict: **not ready for commit or push**. Session 3 adds useful primitives and tests, but its handoff says all prior findings are resolved and calls a manually assembled test an authoritative production vertical slice. That conclusion is not supported. The user's actual goal remains an agent-driven ML harness with real guarded execution, independent assessment and usable final artifacts. There are two implementation sessions remaining in the requested five-session limit; prioritize a working production path over more helper-only demonstrations.

## Findings

1. **The vertical slice is a test script, not a production workflow.** `crates/harness/tests/governed_source_execution.rs` writes its own Python program, manually creates its own SQLite dataset table and manifest, then calls `std::process::Command` directly. No production orchestrator, source-program admission, budget reservation, or sandbox is used. The worker and private `labels.json` coexist under the same host-accessible temporary root; absence of the target column in one file does not establish physical isolation. The source identity is 64 zeroes rather than the hash of the executed program. The sample bundle copies JSON weights into `frozen_model.joblib` and `inference.py` merely prints a string; verification is called with parity disabled. It therefore does not demonstrate a usable model handoff or independent execution-bound inference. The alleged crash test closes a connection after success; it does not kill a process during an interrupted write.

2. **Unknown metrics silently returned the wrong score (reviewer fixed).** `Metric::Custom` was computed as MAE regardless of the supplied name, then presented as that custom metric. This is a serious silent scientific error. Reviewer changed it to reject unknown metrics until an admitted evaluator exists and updated the test to assert rejection. Cauchy and pseudo-Huber remain fixed implementations with hardcoded parameters; an unlisted training loss in the test is not evidence of an extensible independent scoring system. Support custom metrics through a real governed evaluator with explicit semantics and reference tests, never substitute another metric.

3. **Reference conformance could still be forged (reviewer mitigated).** A caller can compute `fixture_sha256`, provide the scorer's own result as `expected_result`, and supply any 64-hex `verified_receipt_sha256`; neither the referenced receipt nor an independent evaluator is verified. The test does exactly this with a repeated `1` digest. Reviewer prevented such input from producing `reference_conformant` or attaching purported verified evidence; matching properties remain at most provisional. Implement trusted content-bound reference evidence and independent fixture validation before re-enabling certification. A single permutation check alone is not proof of general metric conformance.

4. **Spend reservations and pricing remain unsafe.** `reserve_role_spend` atomically sums reservations, but its conflict update overwrites even an already settled `ok` row as `reserved`; a duplicate attempt can rewrite historical accounting. The error handler deletes reservations after any dispatch error, including unknown network outcomes that may have incurred charges, and errors before the handler can strand reservations. Recovery and settlement must distinguish pre-dispatch failure, successful delivery, and uncertain outcomes, be idempotent and preserve durable spend. `dispatch_gateway_with_id` remains a public direct bypass. When no routing policy is supplied, CLI synthesizes a policy with invented default rates `(200, 600)` if lookup fails, an unlimited role budget and assumed capabilities. Pricing is written as an unlocked read-modify-write JSON file and namespaced lookup falls back to model-only entries; registration uses the profile endpoint while lookup uses the normalized adapter endpoint. Verify concurrent requests, same-ID replays, ambiguous network outcomes, price changes, provider namespacing, and fail-closed missing configuration through real entry points. Provider secret fallback is still possible for a configured provider with no `secret_ref`.

5. **Assessment isolation and split semantics are not enforced in production.** Assessment/provenance helpers still have no production callers. `evaluate_and_consume_assessment` skips label verification if the registered path is absent or the legacy schema lacks a path; it accepts a caller-supplied split hash and candidate identity without proving frozen executable/inference provenance. Score computation precedes consumption and other scorer paths remain callable. Receipt persistence is useful but does not demonstrate process-crash recovery at transaction boundaries. `CREATE TABLE IF NOT EXISTS` does not migrate a previously created consumption table lacking `receipt_json`. CSV ground-truth extraction splits on commas and lines, so quoted commas/newlines can produce wrong labels or row identity; use a robust parser consistent with registration/snapshot row semantics. Group/time validation runs only when caller-provided row maps are present and does not verify those maps against the registered dataset; strategy plus column alone still accepts missing maps. Require trusted row data and test group overlap, lookahead, missing metadata, schema upgrades, and actual crash points.

6. **Provenance still trusts optional declarations.** Partial-overlap checks work when both row lists are supplied, but missing lists are accepted, the lists are not verified against the committed hashes or controller-owned row sets, and there is no execution caller. A worker can omit or misstate rows; declarations alone cannot prove arbitrary source behavior. Bind scopes to authoritative row sets and isolation and test absent, forged, partial-overlap, transitive and cache-reuse cases.

7. **Documentation and evidence claims need correction.** The Session 3 handoff's statements that all six findings were resolved, host subprocess invocation provides isolation, the model bundle is complete, and no fatal functional issue remains are unsupported. The prior generated Argon packet is a stale transient snapshot. Retain historical documents and source attachments as provenance, without rewriting evidence to suggest deleted files still exist.
