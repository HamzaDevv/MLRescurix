# Session 2 independent review

Verdict: useful foundations, but the handoff materially overstates completion. The next large batch must integrate and prove the local governed execution path; W4 is not complete merely because manifest/provenance validators exist. The requested general-purpose, agent-authored ML workflow remains unfinished. Keep the master plan and its acceptance criteria authoritative.

1. **Bundle integrity regression (reviewer corrected).** The session changed the verifier to skip `.pyc`, `__pycache__`, and `.DS_Store` before checking file type or symlinks, and omitted those files from manifests. Executable bytecode and even symlinks could therefore escape the exact-file integrity check. The reviewer restored collection and manifest coverage of all files, retained the bytecode-suppression attempt, and added a bytecode/hidden-symlink regression test. The K3 root-cause claim needs evidence under the restored integrity policy; do not ignore executable files to make tests pass.

2. **Assessment is not an end-to-end isolation authority.** `carve_lockbox`, `evaluate_and_consume_assessment`, and provenance checks have no production callers. The helper receives caller-supplied labels and candidate/weight identities; it does not establish independent inference or freeze the source, environment, protocol, model and full assessment receipt in an authoritative workflow. It computes the score before attempting consumption; a process crash after consumption but before receipt return has no full durable receipt recovery. Other scorer paths do not require consumption. It cannot claim one-shot assessment isolation. The reviewer added rejection for mismatched project, dataset ID, and dataset hash, with tests; the full boundary remains outstanding. The group/time checks merely require a named column and do not validate group separation or temporal ordering.

3. **Provider controls remain partial.** Routed CLI is optional; the old direct-dispatch path remains available and benchmark defaults remain hardcoded. Role spend checks read only completed accounting before dispatch, outside an atomic role reservation; concurrent requests and uncertain costs can exceed role ceilings. Pricing is registered by model string in a shared mutable table, allowing provider/model collisions and races. The input context check counts messages but excludes tool schemas and other request content, and provider-side framing is not established as an upper bound. `redacted_only` uses heuristic filtering, not proof of disclosure compliance; caller-supplied provider routing is not bound to the resolved policy. Configured secret lookup can fall through to an OpenRouter key. Protocol implementations, capabilities, retries, escalation/fallback, and actual transport destinations require end-to-end tests. Reviewer fixed endpoint prefix matching, deceptive localhost authorities and fail-open database query errors; this does not solve the broader accounting and routing issues.

4. **Assurance is not evidence-bound.** `evaluate_with_spec_and_evidence` grants `reference_conformant` when an unverified caller passes `true`; no reference identity, fixture result, metric version or receipt is verified. A permutation check alone upgrades assurance, using the legacy evaluator rather than necessarily the requested threshold/variant. Metric support remains a closed enum and class mapping is not frozen. Require independently verified, content-bound reference evidence and explicit metric conventions; keep unverified semantics honestly classified.

5. **Provenance is not a leakage oracle.** A hash of a row set cannot establish subset, disjointness, or overlap: checking only whether two hashes are equal misses partial label/feature overlap. The helper also returns success immediately for stateless/pretrained producers and does not bind protocol hashes between scopes. It is unused in execution. Implement authoritative row-set and transitive dependency validation tied to actual execution, without claiming that declared hashes prove what arbitrary source did. Test partial overlap, differing protocols, cache reuse, and held-out labels.

6. **Cleanup required follow-through.** The packet builder now reports actual source counts. The reviewer updated `scripts/run_m6_review_checks.sh`, which still directed users to the deleted `docs/m6-completion-status.md`. Historical evidence references should remain as historical provenance, not be rewritten to claim a current file. Preserve available original attachments; some removed untracked source reports cannot be recovered from Git. The generated `docs/ARGON_REVIEW_PACKET.txt` is a transient snapshot and includes now-stale claims.
